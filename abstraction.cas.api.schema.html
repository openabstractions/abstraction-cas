Service Store [DEF-S1]

Compare-and-set over a file. This descriptor is emitted as a direct language interface with no IPC. Native providers own locking and replacement. The wire_name is schema metadata, not an available service endpoint.

Interface-only output: implement these methods directly. No IPC client, dispatcher, message envelope or transport binding is emitted. Record codecs remain available. Method return/error signatures are retained; oneway marks the schema declaration, not a delivery or persistence guarantee for a direct call.

Read the current bytes. Absent data means the file does not exist; present empty data means an empty file. Filesystem failures remain implementation errors.

Read

request-response Value

  • Argument 1: string path (required, including zero/false/empty)

Replace only if current value equals base, including presence. A mismatch is Moved. A successful write holds the kernel lock through staging, synchronization and replacement. Missing output data is not an empty write. Existing provider errors remain errors; Change callbacks remain local conveniences.

Write

request-response void

  • Argument 1: string path (required, including zero/false/empty)
  • Argument 2: Value base (required, including zero/false/empty)
  • Argument 3: binary data (required, including zero/false/empty)
